## 逐步动作（翻页顺序）

### 第一步 · 今天只做一件事
- **孩子动作**：听小宇；点「下一页」。
- **画面**：标题「做一首自己的歌」；露出正式名伍澍暘、助手小宇；四格心跳：定义、摆、立刻听、存。
- **带走一句**：今天做 **自己的歌**，不是把别人的歌再做一遍。

### 第二步 · 听歌时你喜欢什么
- **孩子动作**：不说商品歌名。用自己的话说喜欢的感觉：想跑、想静、还是想笑。
- **小宇旁白**：先抓感觉。歌名是别人的，感觉才是你的。
- **带走一句**：先说感觉，不报别人的歌名。

### 第三步 · 选题和心情
- **孩子动作**：在示意芯片上认四颗风格（热血游戏 / 轻松流行 / 安静钢琴 / 电子跳动），再认四颗心情（开心 / 热血 / 安静 / 搞笑）。用一句自己的主题，例如「小忍者穿过竹林，去找会发光的石头」。
- **小宇旁白**：风格是衣服，心情是脸上的表情。主题是这首歌在讲的事。
- **带走一句**：风格一颗，心情一颗，再加上一句自己的事。

### 第四步 · 结构：前奏 / 主歌 / 副歌
- **孩子动作**：指认三段。关掉「前奏」再打开，说开头少了什么。主歌和副歌保持亮着。
- **小宇旁白**：前奏还没开口。主歌在讲事情。副歌是最想跟着哼的那一段。今天最少要有主歌和副歌。
- **带走一句**：主歌讲，副歌记；前奏可以有，也可以先不要。

### 第五步 · BPM 和音色
- **孩子动作**：点 80、110、140，读出屏幕上的数字。再点四种音色：鼓、贝斯嗡音、钢琴、合成铅。
- **小宇旁白**：BPM 是一分钟里有多少拍。80 像散步，110 像走路，140 像小跑。音色是同一种旋律用什么声音发出来。
- **带走一句**：速度看数字，声音点名字。

### 第六步 · 知识卡 · 提示词 · 原创
- **孩子动作**：点开六张知识卡（BPM、小节、主歌/副歌、音色、提示词、原创和抄歌）。听清：提示词是写给爸爸的一段话。
- **小宇旁白**：你不到 13 岁，Suno 由爸爸代操作。我们的页面不登录，也不去连那家网站。
- **带走一句**：提示词交给爸爸。原创可以，抄歌不可以。

### 第七步 · 实操：打开小歌编辑器（不可砍）
- **孩子动作**（横屏可完成）：
  1. 打开编辑器 `?v=mse1`。歌名默认「我的小歌 1」，可以改成自己的题目。
  2. 点一颗风格、一颗心情、一个 BPM（80 / 110 / 140 或滑条上的数字）。
  3. 前奏可关；主歌、副歌留着。点一种音色。
  4. 鼓点 16 下里点亮底鼓 / 军鼓 / 踩镲。旋律在五声（哆来咪嗦啦）上点几个音。
  5. 主题句子写进格子，点 **「生成 AI 提示词」**。
- **小宇旁白**：每一项都有名字，点下去就选中。不要只听一句「换好了」。
- **带走一句**：我在编辑器里摆出了自己的一小段。

### 第八步 · 立刻听（不可砍）
- **孩子动作**：点 **▶ 试听**。改一个鼓点、一个旋律音，或把 BPM 从 80 换到 140，再点一次试听。点 **⏹ 停止**。
- **小测**：快和慢、开心和安静，耳朵分得出吗？
- **带走一句**：改完马上听，这就是编辑器的心跳。

### 第九步 · 存得住（不可砍）
- **孩子动作**：点 **保存「我的小歌」**。看到「已存」。刷新页面，名册里还在，点 **打开**。试一次 **覆盖**，再认识 **删除**（再点一次才真的删）。
- **小测**：存在哪？引导：这台浏览器的本子，键名 `xygo-my-songs`。不是关卡那本。
- **带走一句**：存得住，关掉再打开还是这首。

### 第十步 · 可选 · 爸爸去贴 Suno
- **孩子动作**：把提示词读给爸爸听。爸爸复制，贴进 Suno **简单模式**。孩子不登录、不建号。
- **小宇旁白**：商用 AI 要家长账号。做出来的也必须是新歌，不能把某首买来的歌重做一遍。Udio、MusicFX、Flow 今天都不碰。
- **带走一句**：AI 是爸爸的工具。设计是我的。

### 第十一步 · 收束
- **孩子动作**：一句话「今天我学会了 ___」。一起说口诀。
- **预告（仅预告）**：以后可以一段一个鼓、把歌接到关卡里。今天不改游戏里的声音系统。
- **金句**：先定义，再摆，立刻听，存得住。

## 知识卡（孩子的话）

| 卡 | 就记这一句 |
| --- | --- |
| BPM | 一分钟敲多少下。数字大，歌更赶。 |
| 小节 | 鼓点这一行有 16 下。4 下一组，四组凑成一个小节。 |
| 主歌 / 副歌 | 主歌讲事情。副歌最好记，常常再来一遍。 |
| 音色 | 同一条旋律，钢琴软，合成铅亮，贝斯低，鼓是敲的。 |
| 提示词 | 把风格、心情、速度、结构和你的句子写成一段话，交给爸爸贴给 AI。 |
| 原创 vs 抄歌 | 原创是你的主题，比如忍者冒险。抄歌是照着别人已经做好的歌去仿。今天只做原创。 |
