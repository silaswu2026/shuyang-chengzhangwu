## 2. 四个词 · 定义，摆，立刻听，存

对着屏幕，一个词停一下。让伍澍暘指给爸爸看。

### 定义

先说这首歌是什么。还没出声。

编辑器左边：歌名、风格、心情、BPM、前奏主歌副歌、音色。

每一项都是一颗有名字的按钮，或一个能读出数字的滑条。点中的那颗会亮。

### 摆到格子

鼓点是 16 下。三行：底鼓、军鼓、踩镲。点一下亮，再点一下灭。

旋律是五声：哆、来、咪、嗦、啦。一个格子只放一个音。再点同一个音，就是拿掉。

「清空旋律」「清空鼓点」把整片擦掉。

### 立刻听

▶ 试听从头播。前奏只有鼓。主歌和副歌加上旋律。副歌会高一点、响一点。

⏹ 停止。

改了 BPM、心情、鼓或旋律，再点一次试听，从头听差别。

### 存成数据

摆好的歌不是一张截图。是这台浏览器里的一份数据。

只有点「保存「我的小歌」」，才写进名册。

口诀，一起说一遍：

「先定义。再摆格。立刻听。存进本子。」

## 3. 整条流程 · 想主题，到再打开

小宇按这个顺序带。不要跳。

1. **想感觉。** 不说商品歌名。想跑、想静，还是想笑。
2. **定主题。** 一句自己的事。例如小忍者穿过竹林，去找会发光的石头。
3. **点名字。** 风格一颗，心情一颗，BPM 一个数字，音色一颗。
4. **摆。** 鼓点点亮。旋律点上五声。
5. **听。** ▶ 试听。不对就改一格，再听。
6. **写句子。** 主题写进格子。点「生成 AI 提示词」。这段话先留着。
7. **存。** 点「保存「我的小歌」」。
8. **再打开。** 刷新。名册里点「打开」。歌还在。

带走一句：

「定义，摆，听，再存。这就是小歌编辑器的心跳。」

## 4. 细节 · 每颗按钮叫什么

手机横屏。顶上有一行心跳：「①定义 → ②摆 → ③立刻听 → ④存」。

### 歌名

格子里一开始是 **我的小歌 1**。可以改成自己的题目。别用别人的歌名。

### 风格（四选一）

热血游戏。轻松流行。安静钢琴。电子跳动。

点中的那颗是金色。

### 心情（四选一）

开心。热血。安静。搞笑。

心情会改声音的轻重和长短。安静会轻、会拖一点。热血会更冲。搞笑会短、会有一点俏皮的偏音。

### BPM

三颗预设：**80**、**110**、**140**。旁边滑条从 70 到 140，数字一直显示。

80 散步。110 走路。140 小跑。数字越大，同一条鼓越赶。

### 结构

前奏可以灭、可以亮。

主歌和副歌这一课都要留着。点它们关掉时，会看到一句：主歌和副歌都要留下。

前奏只有鼓。主歌和副歌才有旋律。副歌更高一点。

### 音色

鼓。贝斯嗡音。钢琴。合成铅。

这是旋律用的声音。底下的鼓点格子一直在，不因为你选了钢琴就消失。

### 鼓点

16 下。4 下一组，四组是一个小节。

底鼓常在每组的第一下。军鼓常在第二组和第四组的第一下。踩镲可以密一些。这只是起步，伍澍暘可以改。

### 旋律

上面是高音啦，下面是低音哆。点一格，这一拍就唱这个音。

### 提示词

点「生成 AI 提示词」。下面出现中文和英文。

第一行就写着：13岁以下由爸爸代操作 Suno。

还有一句：不要模仿、不要翻唱、不要抄任何已经出版的歌曲。

「复制提示词」交给爸爸。孩子不打开 Suno。

### 名册

每一首旁边三个字：**打开**、**覆盖**、**删除**。

打开：把那首拿回格子。

覆盖：用你现在摆的，换掉那一首。

删除：先变成「确定删除」，再点一次才消失。

「另存新的一首」会多加一条，不冲掉正在改的那条。

## 5. 数据 · 一把钥匙，和关卡分开

只有一把新钥匙。爸爸只要伍澍暘能说出它不跟关卡混。

| 钥匙 | 它是什么 | 什么时候写 |
| --- | --- | --- |
| `xygo-my-songs` | **小歌名册**。`version` 是 **1**。`songs` 里每一条有 `id`、`title`、`savedAt`、`doc` | 点保存、覆盖、另存、删除、打开（打开会记下最后一首） |
| `xygo-custom-level` / `xygo-my-levels` | 关卡草稿和关卡名册 | 小歌编辑器 **不写** |
| `sycocos-level-progress` | 正式关卡进度 | 小歌编辑器 **不写** |

对伍澍暘说：

「小歌本是 `xygo-my-songs`。关卡本是另一本。两本不夹在一起。」

「没点保存，刷新会回到上次存好的那首。格子上还没存的改动会丢掉。」

下面是形状，给爸爸看懂。鼓点和旋律很长，这里只留头。

```json
{
  "version": 1,
  "lastId": "song-1",
  "songs": [
    {
      "id": "song-1",
      "title": "我的小歌 1",
      "savedAt": "2026-11-03T00:00:00.000Z",
      "doc": {
        "title": "我的小歌 1",
        "style": "热血游戏",
        "mood": "开心",
        "bpm": 110,
        "sections": { "intro": true, "verse": true, "chorus": true },
        "instrument": "钢琴",
        "lyrics": "小忍者穿过竹林，去找一颗会发光的石头。"
      }
    }
  ]
}
```

`lastId` 是「上次打开的那首」。刷新时把它拿回来。`doc` 里还有 `drums` 和 `melody`，各 16 格。

https://silaswu2026.github.io/shuyang-chengzhangwu/shuyang-ai/learn/song-studio/?v=mse1

同一页也可以写成 `index.html?v=mse1`。

小宇：

「点『热血游戏』或你喜欢的风格。」

「点一个心情。」

「点 80，听一次。再点 140，再听一次。」

「鼓点改一格。旋律改一格。再点试听。」

前奏如果灭掉，开头就直接是主歌。主歌和副歌灭不掉。

### 第三步 · 存进名册

点「保存「我的小歌」」。

看见「已存：……」，名册里就有一条，id 像 **song-1**。

只改格子、只点试听，名册还是旧的。一定要点保存。

### 第四步 · 再打开

刷新这一页。

上次那首会回到格子上。名册里点「打开」也是把它拿回来。

点「覆盖」才用现在的格子换掉那一条。点「另存新的一首」才多一条。

## 7. 验收勾 · 看得见，立刻听，存得住

伍澍暘看着屏幕说。爸爸打勾。

- [ ] **看得见。** 点亮的鼓点和旋律，试听时那一列会亮。
- [ ] **立刻听。** 改 BPM 或心情，再试听，耳朵分得出。
- [ ] **存得住。** 刷新以后，名册里还有这首，打开还能听。
- [ ] 能说出四风格、四心情、三种预设速度、四种音色。
- [ ] 能说出：提示词给爸爸。13 岁以下由爸爸代操作 Suno。
- [ ] 能说出：不抄已经出版的歌。主题是自己的。
- [ ] 能说出：小歌键名 `xygo-my-songs`。不写关卡进度。

三连口诀：

「看得见。立刻听。存得住。」

心跳再长一点：

「先定义。再摆。立刻听。存得住。」
