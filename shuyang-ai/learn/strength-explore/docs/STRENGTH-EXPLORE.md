# 今晚探索 · 你更想试试哪样（se1）

给伍澍暘（9 岁）晚上玩的一张成长屋小卷。助手在页面上叫小宇。问的是「你更想试试哪样」，用来挑今晚一件真的会做的事。

声明（第一屏就有，每一屏顶上还留着，原文不改）：

> 成长屋自研兴趣/优势探索；参考 Project Spectrum（表现观察）与青少年优势探索思路；非哈佛官方、非 Gallup 官方、非 WISC、非能力诊断、不定终身职业。

## 这是什么

做法借了两种公开的思路，题目和名字是成长屋自己写的：

- 用一件件能动手的小事来问，不拿抽象性格词问孩子。八个方向：空间摆弄、身体动手、讲故事、找规律、听节奏、和朋友一起、看自然、安静想一想。
- 玩完只亮出今晚更想试的几样（通常三样），每样接一条今晚就能做的事。

这不是任何学校或机构发出的卷子。句子不搬现成量表的原句。选某一边，只说明今晚更想试那一件，不说明已经很会，也不说明别的方向做不了。

## 怎么计

- 28 对，固定顺序。八个方向两两都遇一次，每个方向出现 7 次。左右出现次数只差最多 1，避免老站在左边。
- 两张卡片一样大、一样的字、一样的底。点中之前都不亮。点中之后，不管点哪一张，都是同一种绿。
- 一个方向的次数 = 它被点中的次数，0 到 7。二十八次加起来是 28。
- 亮出时先看次数最高的一组。和第 1 名相差超过 2 次，就不再往下凑。并列的一整组留在一起，不拆开假装排出第二名。次数只写「选中 n 次」，不叫分数。

## 存在哪里

只使用这一把 `localStorage` 钥匙：`xygo-strength-explore`。

不读、不写 `xygo-mi8-results`、`xygo-custom-level`、`xygo-my-songs` 以及任何游戏进度。

钥匙里大致是：

- `version`: 1
- `result`: 最近一次答完的 28 个选择和时间
- `draft`: 没答完的进度。刷新可以接着做

这台浏览器若禁止本地存储，当次仍可做完并看见结果，离开页面后不保留。
