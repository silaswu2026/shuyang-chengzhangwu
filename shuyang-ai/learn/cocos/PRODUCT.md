# 伍澍暘成长屋 · 产品需求（Cocos 统一课件）

状态：草稿待 Silas 批标题与六步文案  
对照：`DESIGN.md` · `PLAYER-TEST-CASES.md`  
正式名：**伍澍暘**（禁「五树杨 / 伍树杨」当正式名）· 助手：**小宇**  
引擎：仓库内 Cocos2d-JS Lite v3.13（与今晚工坊同族）；课件主路径统一 Cocos，不另开半套 HTML 控件抢同一交互。  
主看设备：**手机横屏**（另须竖屏与桌面可玩）。

## 0. 产品一句话

孩子打开小屋 → 选一门课件/一关 → 在 Cocos 里走完 **六步教程** → 立刻 **单机试玩** 或 **联网试玩**；全程海军蓝·金·绿一家风，姓名露出正确，手机横屏可用。

## 4. L2 课件内部教程（六步）— 需求与验收

统一 Cocos 场景翻页（或同场景六层），顶栏显示 ①…⑥；当前步绿色，其余海军蓝。小宇在左，爸妈在右。

### 六步定义（提案，Silas 可改标题，不可删「可跑一次 / 能去试玩」）

| 步 | 标题（提案） | 孩子做什么 | 必有控件/画面 |
| --- | --- | --- | --- |
| ① | 看图上钩 | 看懂「上钩 / 自己决定停」 | 插画在壳内画布；一句旁白 |
| ② | 频率 | 调地刺间隔，跑一次，说哪点在钓你 | 真滑条约 1–5s + 加减 +「跑一次」 |
| ③ | 摆关 | 放陷阱与金币，遵守前两格安全 | 短筹码横滑：刺/火/弹/雾/石/币/擦 |
| ④ | 装备 | 用钱包买/装备武器（同页不另开第五课壳） | 飞镖15 / 砍刀35 / 枪60；钱不够买不了 |
| ⑤ | 觉察 | 玩完问一句；准备去玩 | 问句 + 去玩 + 联机游玩入口 |
| ⑥ | 听选音频 | 先听后选 BGM/SFX（喇叭抽屉升格为第六步或与⑤并列可进） | 四心情 BGM + SFX；署名 Kevin MacLeod / Kenney；禁 Mixkit |

说明：相对旧「四步」——①②③⑤ 对应旧看图/频率/摆关/觉察；④从摆关内武器店拆成显式一步；⑥把「先听后选」收成可验收步骤。若 Silas 要换⑥内容，改标题与验收表，不改 L3 试玩合同。

### 壳与横屏
- 电脑壳 / 手机壳可切；**手机横屏为今晚主验分辨率**（约 844×390）：画布必须落在金框/壳内，禁止 `fixed` 飞出视口；16:9 槽不得被巨大空边挤没互动区。
- 底栏拇指优先：「跑一次」在横屏仍易点（可达、不小于约 44px 高）。
- Boot 有时限兜底；失败诚实报错，不静默假成功。

## 5. L3 试玩（单机 + 联网）— 需求与验收

### 单机
- 从⑤「去玩」进 `custom-play`；无存档用 `tonight-waves-v1`。
- 第一帧合法精灵（绿/红/蓝忍者之一，非白底方块）；走跳吃币受伤反馈正常。
- 「回工坊」回新工坊，不回旧 `level-design`。

### 联网
- **沿用旧联网做法**（真 PeerJS / 既有开房进房）；入口：工坊顶栏「联机」、右轨 🤝、⑤「联机游玩」→ `custom-play?net=1`；备路 `xy-go`。
- **不更换**联网技术栈；联网局 UI/角色必须与 Cocos 课件风格一致（三忍者）。
- **单人优先**：`?net=1` 不挡关；「等另一位」不得挡住移动；取消房间卡 ≠ 强制结束单人局。
- 不做假在线动画；微信内提示系统浏览器。

## 8. Silas 补充硬标准（2026-11-01）

### 8.1 全游戏风格统一
- **需求**：封面、选课、六步课件、单机试玩、联网试玩共用同一视觉语言（海军蓝·金·绿 `brand-tokens`、同一套 UI 壳/圆角画布习惯、同一插画粒度）；禁止课内一风格、试玩另一套「陌生游戏」感（玩法 HUD 可简化，但色板/角色/地形材质须一家风）。
- **验收**
  - P-S1-1（P0）：任意主路径截图并排，色板与壳不一致即不合格。
  - P-S1-2（P1）：旧旁路页可保留，但不得从课 3 主 CTA 误进「另一套皮肤」当主路径。

### 8.2 角色仅绿 / 红 / 蓝三忍者
- **需求**：孩子可操纵与主镜里出战的角色 **只许** 仓库已有绿忍者、红忍者、蓝忍者三套；不新开第四可控主角，不用绿色小人头像顶替正式头像，不把无关动物皮当主控角色。Boss/小怪仍走名册允许列表（与「主控三忍者」分开）。
- **验收**
  - P-S2-1（P0）：课件演示、试玩、联网局里主控皮肤 ∈ {绿, 红, 蓝} 忍者。
  - P-S2-2（P0）：选人/换人 UI 若存在，选项不超过这三色。
  - P-S2-3（P1）：头像区仍用家人正式图；不拿忍者帧冒充伍澍暘/小宇头像。

### 8.3 联网沿用旧做法、不换栈
- **需求**：联网继续现有 **PeerJS（+ BroadcastChannel 本机兜底）** 方案与现入口（`custom-play?net=1` / 工坊联机 CTA / `xy-go` 族备路）；**不**新上自建房间服、不换 WebRTC 封装栈、不做「假联机」动画冒充。
- **验收**
  - P-S3-1（P0）：联机实现仍可在现有 `custom-play.js` / PeerJS CDN 路径上指认，无新强制后端。
  - P-S3-2（P0）：单人优先规则不变（net=1 不挡关）。
  - P-S3-3（P2）：微信内 WebRTC 限制仍提示系统浏览器。

### 8.4 联网局画面与 Cocos 课件引擎风格一致
- **需求**：联网对局的舞台（地形、三忍者、陷阱表现、壳外 HUD 气质）须与 **Cocos 课件/试玩** 同一引擎风格与资源族，避免「课件是 Cocos 细插画、联网却是另一套 canvas 皮」。允许 HUD 文案差异，不允许材质/角色比例/色板漂移成另一产品。
- **验收**
  - P-S4-1（P0）：从⑤联机游玩进入的对局，角色与场景可读作与 `custom-play` / 工坊画布同族。
  - P-S4-2（P1）：若暂经 `xy-go` 备路，须在 PRODUCT/DESIGN 标成过渡；主验收以 Cocos 风格路径为准，备路风格漂移记 P1 直到并回。
