## 1. Silas 口述（保留）

试玩最后一章：

- 进入**单机**游戏；
- **单机 + 联机**机制与老版本一致；
- 界面换成与**现在 Cocos 2D 界面**一致的风格；
- **不能跳到新界面**（不能变成另一套陌生 UI）；
- 游戏核心和联网部分**不变**；
- **只换壳**，变成一个整体。

---

## 2. 目标一句话

L2 工坊（`visual-workbench` / `workbench`）与 L3 试玩（`custom-play`）在**色板、壳语言、角色皮、导航习惯**上读作同一产品；孩子从⑤「去玩」出去时，像换房间不换房子。玩法与 PeerJS **不重写**。

---

## 3. 现状 vs 目标

| 层 | 现状（main） | 目标（本方案） |
| --- | --- | --- |
| 主试玩页 | `custom-play.html` + `custom-play.js` | **仍是主路径**；继续收 chrome 与工坊 token 对齐 |
| HUD / 顶栏 | 已部分 navy·金·绿（brand-tokens）；血条/币/武器条已收 | 与工坊顶栏 chip / 金边圆角**同族**；禁止回沼泽皮当主壳 |
| 舞台 | canopy-night / 泥土草线同族；`gy≈H*0.28` | 保持可玩；壳外框更像工坊金框习惯（提案） |
| 联网 | **PeerJS** + BroadcastChannel 兜底；`?net=1` 单人优先 | **不换栈**；房间卡视觉跟工坊联机卡同族 |
| 备路 | `xy-go/?custom=1` 公园/沼泽 HUD | **继续标过渡**；主验收不认备路皮；不把孩子主 CTA 指到备路 |
| 从⑤出口 | 「去玩」「联机游玩」→ `custom-play` | 禁止改跳到全新域名/全新框架页 |

### 工坊壳 token（对齐源）

- `brand-tokens.css`：海军蓝 `#0f1230` · 金 `#ffe07a` · 绿 `#3ecf6a`
- 双壳：电脑壳 / 手机壳（`.phone-bezel` 金框、16:9 槽）
- 顶栏步骤绿当前 / 海军蓝其余

试玩**不必**复刻整颗手机凹槽硬件皮（可 TBD），但色板、圆角、按钮梯度、字体粗细须一家风。
