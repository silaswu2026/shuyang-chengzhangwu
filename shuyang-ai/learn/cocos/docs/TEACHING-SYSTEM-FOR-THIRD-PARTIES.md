## 产品总论 · 双轨始终并行

Silas 与成长屋把教学做成 **两条轨道同时跑**，缺一不可：

| 轨 | 名字 | 每天在做什么 | 产物 |
| --- | --- | --- | --- |
| **轨 1 · 日课共学** | 和伍澍暘一起学、一起总结 | 开会选题 → 当堂逐步做 → 口头复盘 | 孩子真会的技能 + 当日笔记 |
| **轨 2 · 课件产品化** | 把日课沉淀成第三方能用的课 | 把步骤、旁白、验收、壳写成文档与可跑页 | Curriculum Pack / Course Shell / 可分发课包 |

**产品命题**：  
> 先有真实孩子的「学会」，才有可卖可授的「课件」。  
> 日课不是演示稿；课件不是事后补作业——**同一天的学习，既服务伍澍暘，也写成别人能照做的系统。**

第三方接入时，请同样保持双轨：内部试点学员（轨 1）+ 当天把步骤产品化（轨 2）。只做其中一条，体系会空或会腐。

## 二、课件结构与「逐步动作」范式

### 2.1 单课标准骨架

```text
封面 / 点名今天只做一件事
  →（可选）对照旧知或「玩 vs 造」
  → 编号步骤 第一步、第二步…（每步：小宇旁白 + 孩子动作 + 带走一句）
  → 当堂实操 / 试玩（不可砍）
  → 短验收（Jobs 产品官 + 玩家测双角色）
  → 收束与下次预告
```

### 2.2 步骤写作模板（轨 2 当天要落盘的）

每一步固定四格：

1. **孩子动作**（可点、可拖、可说）  
2. **小宇旁白**（一句人话，忌讲义腔）  
3. **画面 / 壳**（哪一页、哪块高亮）  
4. **带走一句**（当晚能复述）

另附：时间盒表、P0/P1 验收表、旁白总串。

### 2.3 壳与芯片范式（本仓已验证）

- **四芯片 / 六步工坊**：看图 · 关卡设计（摆关|设置|关联）· 觉察 · 听选 —— 可按课裁剪。  
- **手机横屏优先**（~844×390）与电脑壳可切换。  
- **cover → select → numbered steps → playtest → acceptance**。  
- **Git 铁律**：讲义与可跑页进 `main` Pages，不云端私藏。

### 2.4 双角色验收

| 角色 | 问什么 |
| --- | --- |
| **Jobs / 产品官** | 步骤是否必要？姓名/品牌锁？P0 是否可当堂证伪？ |
| **玩家测** | 孩子路径是否卡住？横屏是否糊/飞出壳？存档再打开是否灵？ |

## 三、核心思想（可对外讲的「成长屋教学法」）

### 3.1 链条：画面 → 机制 → 沉浸

1. **画面**：角色、背景、帧 —— 先看得见。  
2. **机制**：道具/陷阱/奖励、关卡规则、编辑器 —— 能改能造。  
3. **沉浸**：钩子与心流 —— 以及 **上钩觉察 / 自己决定停** 的双轨伦理。

### 3.2 四条操作原则

| 原则 | 含义 |
| --- | --- |
| **知识点递进** | 不跳步；新课默认建立在已会的零件上 |
| **课题自选** | 菜单提出，孩子选主课，提升所有权 |
| **边做边学** | 每课必有不可砍的实操；讲义服务动手 |
| **上钩觉察双轨** | 既教「怎么钓人」，也教「怎么停」；产品不得只卖上瘾 |

### 3.3 产品级锁（第三方必须当规则，不当风格建议）

- 正式学员姓名以签约锁为准（本示范锁 **伍澍暘**，禁错字）。  
- 助手名锁定（本示范 **小宇**）。  
- 品牌色板锁定（本示范海军蓝 · 金 · 绿）。  
- 可玩角色集合锁定（本示范仅绿/红/蓝忍者）。  
- 自定义关与正式关名册隔离。

## 四、如何产品化成第三方可用系统

### 4.1 模块划分

| 模块 | 职责 | 本仓对应物（示例） |
| --- | --- | --- |
| **Curriculum Pack** | 课题菜单、顺序、自选规则、金句 | docs 课纲 + 课题表 |
| **Course Shell** | 编号步骤 UI、旁白、时间盒、手机壳 | `classroom/` · `visual-workbench` |
| **Play Runtime** | 真正可玩的关 | `custom-play` · 正式关进度 |
| **Editor Kit** | 摆关、存档 schema、我的关名册 | workbench 摆关 · `xygo-custom-level` |
| **QA 双角色** | Jobs 验收表 + 玩家测用例 | `PLAYER-TEST-CASES.md` · Jobs QA |
| **Git Sync 铁律** | 课包与 Pages 同源 | push `main` |

### 4.2 第三方工作室使用流程

1. **选试点学员**（启动轨 1）→ 锁正式名/助手名/品牌。  
2. **开课题菜单** → 学员自选主课。  
3. **当天共学**（轨 1）→ 按「步骤模板」实录动作与失败点。  
4. **当天落盘**（轨 2）→ COURSE 文 + course-today.json + 验收行。  
5. **壳上接线** → Shell 步骤指向 Runtime / Editor Kit。  
6. **双角色测** → 不过不标完成。  
7. **推送可分发课包** → 第三方只克隆 Pack+Shell 配置即可换皮。

### 4.3 适配其他游戏类型

教学法（编号步骤、自选课题、边做边学、上钩觉察）**保持不变**；只换 **零件架与钩子表**：

| 类型 | 换掉的 | 保持的 |
| --- | --- | --- |
| 平台跳跃（本仓） | 跑道、陷阱、金币 | 步骤范式、双轨、验收 |
| 解谜 | 拼图块、规则面板、提示预算 | 同上 |
| 射击 / 闪避 | 弹幕图案、安全区、弹药 | 同上 |
| 叙事冒险 | 选项节点、线索板 | 同上 |

**适配口诀**：换 palette + hooks；不换 pedagogy。

### 4.4 给第三方的最小交付清单

- [ ] 双轨说明（本文 §产品总论）写入他们的 README  
- [ ] 一套 Curriculum Pack（≥3 课题菜单）  
- [ ] Course Shell 能跑「十步内」一课  
- [ ] Play Runtime 与 Editor Kit 至少一条通路  
- [ ] Jobs + 玩家测各 5 条 P0  
- [ ] 姓名/品牌/角色锁表  
- [ ] Git/Pages 或等价公开预览
