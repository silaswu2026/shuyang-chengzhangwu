## 逐步动作（顶栏 / 翻页顺序）

### 第一步 · 今天只做一件事
- **孩子动作**：听小宇；点「开始」。
- **画面**：标题「关卡编辑器 · 从零」；露出正式名伍澍暘、助手小宇。
- **带走一句**：今天只学 **造关的工具**，不是玩别人做好的关。

### 第二步 · 玩关 vs 造关
- **孩子动作**：看左右对照——左「只能玩现成关」；右「自己拖陷阱/金币再试玩」。点「我想站右边」。
- **小宇旁白**：玩关 = 当玩家；造关 = 当小小设计师。编辑器帮你站右边。
- **带走一句**：编辑器不是关，是 **造关的工作台**。

### 第三步 · 编辑器要达到的效果（三连）
- **孩子动作**：点亮三张效果卡：① **看得见**（摆的和玩的差不多）② **立刻试**（改完马上跑）③ **存得住**（下次还能打开自己的关）。
- **小测**：缺哪一张，编辑器就不完整？
- **带走一句**：看得见 · 立刻试 · 存得住。

### 第四步 · 三块面板认界面
- **孩子动作**：在示意壳上依次点：
  1. **零件架**（起点 / 陷阱 / 金币 / 终点…）
  2. **画布**（往地上摆）
  3. **试玩 · 保存**（跑一把 · 存「我的关」）
- **小测**：小宇故意指错区一次，伍澍暘纠正。
- **带走一句**：架 → 画布 → 试玩，三步循环。

### 第五步 · 零件维度（今天够用的）
- **孩子动作**：在零件架上认四类标签并各点一颗：
  - **起点**（忍者从哪冒出来）
  - **挡人**（陷阱：刺 / 火 / 沼…）
  - **钓人**（奖励：金币 / 宝箱）
  - **终点**（通关门 / 宝箱）
- **规则卡**：前两格安全（不能放危险陷阱）——与现工坊一致。
- **带走一句**：今天先用这四类；以后再加地形层、难度层。

### 第六步 · 怎么摆才算「设计」
- **孩子动作**：听小宇短示范（不代劳）：先放起点 → 中间放 1～2 个挡 → 夹几枚金币 → 终点放远一点；中间留路。
- **钩子一句（轻提，不展开旧课）**：太简单会无聊，太难会放弃；今天只求「能跑通、有一点刺激」。
- **带走一句**：设计 = 用零件讲一个「过关的小故事」。

### 第七步 · 实操：摆通第一关（不可砍）
- **孩子动作**（限时清晰、横屏可完成）：
  1. 拖 **1 起点** + **2 陷阱** + **3 金币** + **1 终点**
  2. 点 **试玩**，自己跑到终点（过不去就回画布改）
  3. 点 **保存「我的第 1 关」**（本地名册；**不与正式 1–8 Boss 混表**）
- **小宇旁白**：摆 → 玩 → 改 → 再存；这就是编辑器的心跳。
- **带走一句**：我用编辑器做出了 **自己的一关**。

### 第八步 · 再打开 · 证明存住了
- **孩子动作**：从「我的关」或选关第 9 /「玩我的关卡」再进一次刚存的关；确认零件还在、能再跑。
- **小测**：说「存档在我这边」还是「只在这一次页面里」？（引导：本地名册，刷新后仍在。）
- **带走一句**：存得住，才叫真正的编辑器。

### 第九步 · 钩子自检（一分钟）
- **孩子动作**：对自己的关勾两问：
  1. 有没有 **至少一个惊喜**（金币或陷阱位置让人「哦」一下）？
  2. 开玩前我有没有 **自己定停点**（玩几分钟 / 通一关就停）？
- **带走一句**：会做钩子，也要会自己停。（点到为止，不展开旧四段。）

### 第十步 · 收束 · 下次加深
- **孩子动作**：一句话「今天我学会了 ___」；听预告。
- **预告（仅预告，不当堂做）**：撤销/重摆、更多零件、难度自检；一系列关卡、联网以后开课。
- **金句**：会玩关 → 会改关 → 会造编辑器。
