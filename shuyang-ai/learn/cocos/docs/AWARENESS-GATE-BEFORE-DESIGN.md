## 4. 样题草案（待 Silas 改文案）

教义对齐今晚课：钩子 / 难度节奏 / 「复杂≠难」。

| 问 | 样题意图 | 示例选项（TBD） | 期望方向（TBD） |
| --- | --- | --- | --- |
| 最难 | 区分「难」=玩家压力大（密刺+短反应） | A 很多陷阱挤在一起 B 只有一个金币 C 很长但不危险 | 偏 A 类 |
| 中间 | 「玩法中等」=有一点要想、还能过 | A 全平地无互动 B 少量刺+间隔可跑 C Boss 秒杀 | 偏 B 类 |
| 最复杂 | 「复杂」=元素种类/规则多，未必最难 | A 一种刺重复 B 火+雾+弹跳+宝箱组合 C 空关 | 偏 B 类 |

**对错规则（提案）**：

- 每问有「更合适」选项；允许一次改选。
- **不严厉**：判错时小宇说「再看一眼钩子」+ 高亮提示，不扣练习金、不锁死。
- **通过条件（提案）**：三问至少 2 对，或三问都做过并看过反馈 → 可进设计。（精确阈值 **TBD**）
