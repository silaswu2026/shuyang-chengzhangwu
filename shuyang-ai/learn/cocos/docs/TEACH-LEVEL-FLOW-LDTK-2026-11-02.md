## 2. 四个词 · 对照 LDtk / Tiled，落到我们的工坊

对着屏幕，一个词停一下。让伍澍暘指给爸爸看。

### 零件定义

大厂先规定「这种东西是什么」。

LDtk 里，这叫实体定义，还可以分层。一层地板，一层人或陷阱。

Tiled 里，图块是一种定义，物件是另一种定义。刺是刺，旗是旗，先在零件表里说清楚。

我们的工坊：上面那排小筹码。起、刺、火、金币、终。

这是种类。还不是这一关里的那一颗。

### 摆到格子

定义好了，才往这一关里放。放下去的那一颗，叫实例。

LDtk：把实体摆到某一层的格子上。同一种实体，可以摆很多个。

Tiled：图块铺进图层。起点、终点这类，放进物件层。

我们：中间十二格。先点一种零件，再点一格。

两格都是刺，就是两个实例。种类还是同一个「刺」。

### 存成数据

摆好的关，不是一张截图。是一份游戏能读的数据。

LDtk、Tiled 都把关存成文件。游戏引擎再打开这份文件来跑。

我们存在手机浏览器里。摆的时候，写进草稿槽。

槽的名字是 `xygo-custom-level`。版本号是 **1.2**。

满意了，再点「存我的第1关」。一份抄进名册 `xygo-my-levels`，条目 id 是 **my-1**。

改了格子，名册不会偷偷变。要再点一次保存，名册才更新。

### 立刻试玩

LDtk 和 Tiled 自己不替你跑完整局。它们把数据交给游戏，改完就再跑。

我们按「试玩」。试玩页马上读同一份草稿槽。

跑不过，退回来挪一格，再试。这就是编辑器的心跳。

口诀，一起说一遍：

「先定义。再摆格。存成数据。立刻试玩。」

## 3. 整条流程 · 想故事，到再打开

小宇按这个顺序带。不要跳。

1. **想故事。** 忍者从哪出发。中间躲什么。最后跑到哪。
2. **认架。** 零件架上先认四类：起点、挡人、钓人、终点。
3. **摆。** 点零件，再点格子。前两格先让人站稳。
4. **试。** 点「试玩」。自己跑到终点。
5. **改。** 过不去就回来。擦掉一格，或挪开一点。再试。
6. **存。** 能跑通了，点「存我的第1关」。
7. **再打开。** 选关第 9，或工坊上的「再打开」。零件还在，就能再跑。

带走一句：

「摆，玩，改，再存。这就是编辑器的心跳。」

## 4. 细节 · 三块面板、四类零件、前两格、一句节奏

### 三块面板

摆关页顶上有一行字：

「①零件架 → ②画布 → ③试玩·保存」

1. **零件架**：上面那排筹码。先选种类。
2. **画布**：中间十二格。格子从左到右标着 1 到 12。点一格，东西才落地。
3. **试玩 · 保存**：底下三个钮。试玩。存我的第1关。再打开。

小宇可以故意指错一块。伍澍暘来纠正。

### 四类零件

今天只用这四类。筹码上的字，帮你找到它们。

| 四类 | 孩子怎么叫 | 筹码上看见 |
| --- | --- | --- |
| 起点 | 忍者从这一格出发 | 起 |
| 挡人 | 会挡住或弄疼 | 刺、火、沼、石、电、凹 |
| 钓人 | 想过去拿的奖 | 小金币、大金币、宝箱 |
| 终点 | 跑到这一格就过关 | 终 |

弹簧可以踩。它不是危险陷阱。前两格也可以摆弹簧，也可以摆起点。

擦，是橡皮。点「擦」，再点一格，那一格就空了。

### 前两格安全

最左边第 1 格、第 2 格，不能放危险陷阱。

刺、火、沼、石、电、凹，放进去会提示：开头要空着。

像刚出生要先站稳。先走两步，再遇见第一下刺激。

金币、起点、终点、弹簧，前两格可以放。

### 节奏一句

不太简。也不要太难。

太空、太直，会无聊。陷阱排太密、不留路，会放弃。

今天只求：能跑到终点，中间心跳一下。

建议先摆这几个，再自己挪：

**1 个起点，2 个陷阱，3 枚金币，1 个终点。**

起点放最左。终点放最右。中间留出路。

## 5. 数据 · 三把钥匙分开，外加一个迷你形状

三把钥匙不混。爸爸只要伍澍暘能说出前两把的差别。

| 钥匙 | 它是什么 | 什么时候写 |
| --- | --- | --- |
| `xygo-custom-level` | **草稿槽**。正在摆、正在试的这一份。版本一直是 **1.2** | 点格子、点试玩，都写它 |
| `xygo-my-levels` | **名册**。里面一条 id 是 **my-1**，标题「我的第 1 关」 | 只有点「存我的第1关」，才把草稿整份抄进去 |
| `sycocos-level-progress` | **正式进度**。只记第 1 到第 8 关试过没有、过关没有 | 工坊不写它。试玩 `level=9` 也不写它 |

对伍澍暘说：

「草稿槽是桌上的纸。你一改，纸就变。」

「名册是夹进本子的那一页。你点保存，才夹进去。」

「学校成绩单只记正式 1 到 8。我的关不进成绩单。」

下面是形状，给爸爸看懂。不要整段贴进游戏。钱包、音乐、音效都省掉了。

点过「存我的第1关」之后，草稿槽大致是这样。十二格从 0 数。0 是画面上的第 1 格。11 是第 12 格。前两格没有刺，也没有火。

```json
{
  "version": "1.2",
  "cols": 12,
  "editor": { "startX": 0, "goalX": 11 },
  "mine": {
    "map": ["start", null, "coin", "spike", null, "coin", "coin", null, "fire", null, null, "goal"]
  },
  "myLevelId": "my-1",
  "myLevelTitle": "我的第 1 关"
}
```

名册是另一把钥匙。它只是把上面那份抄进 `doc`：

```json
{
  "version": 1,
  "levels": [
    { "id": "my-1", "title": "我的第 1 关", "doc": { "version": "1.2" } }
  ]
}
```

之后再改格子，先变的是草稿槽。名册里的 `doc` 要等下一次「存我的第1关」。

## 6. 实操 · 硬刷地址，按顺序点

手机横屏。地址整段复制。`v=ldt33`、`v=c52`、`v=ls3` 就是硬刷记号。

### 第一步 · 打开摆关

https://silaswu2026.github.io/shuyang-chengzhangwu/shuyang-ai/learn/cocos/visual-workbench.html?v=ldt33&step=2

`step=2` 直接停在摆关。看见「①零件架 → ②画布 → ③试玩·保存」。

小宇：

「点『起』，再点最左一格。」

「点『终』，再点最右一格。」

「中间摆两处挡，三枚金币。留一条能过去的路。」

前两格如果塞进刺或火，听到「开头要空着」，就换到第 3 格以后。

### 第二步 · 立刻试

点底下的「试玩」。会打开：

https://silaswu2026.github.io/shuyang-chengzhangwu/shuyang-ai/learn/cocos/custom-play.html?v=c52&level=9

自己跑到终点。

过不去，退回工坊，改一格，再点试玩。

这一页是第 9 关。它不写正式 1–8 的进度。

### 第三步 · 存进名册

跑通了，回工坊，点「存我的第1关」。

看见「已存：我的第 1 关」，名册里就有 **my-1** 了。

只点格子、只点试玩，名册还是旧的。一定要点这一下。

### 第四步 · 再打开

打开选关：

https://silaswu2026.github.io/shuyang-chengzhangwu/shuyang-ai/learn/cocos/level-select.html?v=ls3

点第 9 张卡「我的关卡」，或「玩第9关 · 我的关卡」。

它先把名册 **my-1** 抄回草稿槽，再进试玩。

工坊上的「再打开」做同一件事。也可以整段重开摆关：

https://silaswu2026.github.io/shuyang-chengzhangwu/shuyang-ai/learn/cocos/visual-workbench.html?v=ldt33&open=my1&step=2

`open=my1` 就是「从名册把我的第 1 关拿回桌上」。

零件还在，再跑一遍。这才叫存得住。
