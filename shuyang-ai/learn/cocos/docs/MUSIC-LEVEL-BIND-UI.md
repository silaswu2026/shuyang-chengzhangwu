## 2. 调研摘要（成熟编辑器 / 横版 · 音乐↔关卡）

| 产品 | 模式 | 对孩子课件的启发 |
| --- | --- | --- |
| **RPG Maker MZ** | 地图属性「Autoplay BGM/BGS」：进图自动播；同曲不重切；可 `(None)` 停 | **单关字段**：每关一条默认 BGM；预览在属性窗 |
| **Super Mario Maker 2** | Course Theme 定默认曲；SFX 面板可放「换曲触发」 | **默认曲 + 区内触发**两层；编辑时主题即听感 |
| **Unity（常见做法）** | 持久 BGMManager + 每场景/关组件挂 `AudioClip` | **关卡组件字段**；跨关不重载管理器 |
| **GDevelop** | 场景属性「进场停不停音乐」+ 事件播曲 | 关卡属性决定是否换曲 |
| **Construct 3** | Music 文件夹 + 布局 Start 播；防重复播 | 布局级绑定；预览靠编辑器播放 |

**归纳出的四类模式**（本方案只用前两类做主 UI）：

1. **Per-level BGM 字段**（RPG Maker / Unity 组件）— 选关 → 设默认曲  
2. **Playlist / 曲库先听再挂关**（接近我们现「先听后选」）— 选曲 → 勾哪些关用它  
3. **Zone / 触发换曲**（Mario Maker 音效块）— 本期 **不做**（复杂度高，留给以后）  
4. **Preview-while-edit** — 编辑时点「试听」即播，不进试玩也能听到  

来源：
- [RPG Maker MZ · Map Properties](https://rpgmakerofficial.com/product/MZ_help-en/01_07_03.html)
- [SMM2 Course Maker / 换曲指南](https://supermariomaker2.fandom.com/wiki/Course_Maker)、[Attack of the Fanboy](https://attackofthefanboy.com/guides/super-mario-maker-2-how-to-change-music/)
- [GDevelop Audio](https://wiki.gdevelop.io/gdevelop5/all-features/audio/)
- Unity 社区：场景级 BGMManager + DontDestroyOnLoad 模式（Discussions / 常见教程）

## 6. 数据模型草图（只方案，不实现）

### 6.1 建议结构（存档旁路）

在 `xygo-custom-level` v1.2 **旁**增加（或同对象新字段，拍板后定版本）：

```json
{
  "audio": {
    "bgmId": "explore",
    "sfx": { "...": true }
  },
  "levelAudio": {
    "1": { "bgmId": "explore" },
    "2": { "bgmId": "tense" },
    "9": { "bgmId": "explore", "sfxPreset": null }
  }
}
```

| 字段 | 含义 |
| --- | --- |
| `audio.bgmId` | **全局回退** / 未挂关时的默认；保留现行为 |
| `levelAudio["1"…"9"].bgmId` | 该槽默认探索曲；缺省 → 回退 `audio.bgmId` |
| `levelAudio[n].sfxPreset` | 预留；本期 `null`，SFX 仍读全局 `audio.sfx` |
| 存储键提案 | 仍用 **`xygo-custom-level`**（扩展字段）；正式 1–8 日后若进仓库名册，可镜像到 `data/level-audio.json`（TBD） |

### 6.2 播放优先级（试玩读档时 · 提案）

1. 当前 `levelId` 的 `levelAudio[id].bgmId`  
2. 否则 `audio.bgmId`  
3. 事件曲：受伤/失败仍可切 `fail`，过关切 `win`（现逻辑保留；是否覆盖关卡默认曲 → 待拍板）

### 6.3 与四心情关系

- 曲库 **仍只有** explore / tense / win / fail  
- 绑定 =「哪几关默认播哪首心情曲」  
- **不**引入新曲文件；**不**删四心情 UI
