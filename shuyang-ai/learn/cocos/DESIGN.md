## 课的路径

主路径只有四步，不另开第五步：

1. **看图** — 上钩，以及自己决定停
2. **频率** — 一个旋钮：地刺每几秒冒一次，跑一次，再回答哪一点在钓你
3. **摆关** — 放东西、调数字、跑一次；商店和后加的陷阱也在这一步，不单独成课
4. **觉察** — 玩完问一句，并去玩这一关

「去做 → 测一次 → 说感觉」是这课的中心。去玩是旁边的一条路，进 `custom-play.html`。旧课件上的「做得更好」演示和完整音频课本先不做。

顶栏文案与旧今晚页一致：① 看图一句、② 频率、③ 设计一小关、④ 玩完。当前步是绿色，其余是海军蓝。小雨在左，爸爸和妈妈在右。

## 画面方向

目标是旧今晚页的版式、颜色和句子，再用更细的 Cocos 插画画出来。

旧页是深色壳（约 `#0f1230`），中间一块圆角画布（频率和摆关的底是 `#6ec8ff`），标题和旋钮在画布外面，脚上是上一步 / 下一步。插画本身沿用旧画布和 `ld-art.js`：水面和钩、蓝天远山、泥土地加草、格子上的道具。要加的是光、材质和层次，不是另一套粗色块。

已经做上的（wb5）：

- 小图在 `wb-art.js`：鱼、金属钩、水面高光、天空渐变、远山近山、带石子的泥土、草叶、刺、火、金币、弹簧、迷雾、岩石。
- 看图、频率、**摆关**都收进深色壳里的圆角画布；标题在画布外。
- 频率有 **真拖滑条**（1–5 秒）＋加减按钮。
- 摆关陷阱条压成短筹码（刺/火/弹/雾/石/币/擦），武器店仍在同一页。
- 忍者放大（频率≈112、摆关≈120、试玩 `CHAR_FRAC=0.20`）。
- 手机壳：顶栏用 ①②③④ 短标签、略大触控；桌面保留长文案。
- 启动：`#boot` 有 7s/9s 兜底，避免卡在「正在打开课件…」。
- 无存档时用 `tonight-waves-v1` 四波默认跑道（与 custom-play / xy-go 同源）。

还薄的：觉察页画布层次、先听后选音频条（归音频工人）、关卡升级壳（归壳层工人）。

## 陷阱

摆关工具：地刺、火、弹簧、迷雾、岩石、金币、擦掉。

| 格子 | 课上的意思 | 试玩里 |
| --- | --- | --- |
| 地刺 | 每 1 / 3 / 5 秒冒一次 | 冒起时扎人 |
| 火 | 停 1 / 3 / 5 秒 | 一直在，按伤害掉血 |
| 弹簧 | 踩上去会弹起来 | 落地时向上弹 |
| 迷雾 | 走进去会变慢 | 短时间减速，并蒙一层紫 |
| 岩石 | 撞上去会轻伤 | 挡住身体，撞一下掉 1 血 |
| 金币 | 奖励，用来喘气 | 捡到加金币 |

前两格是出生点。地刺、火、弹簧、迷雾、岩石不能放在那里。预计掉血：岩石算 1，弹簧和迷雾算 0，地刺和火沿用原来的估算。检查条仍是：开头空着、先易后难、有喘气、花样不超过 3。

## 金币、武器、存档

键名 `localStorage` 的 `xygo-custom-level`。版本 **1.2**。可附带 `music`、`likes`（本机）；试玩积分写 `lastScore`。

键名仍是 `localStorage` 的 `xygo-custom-level`。版本 **1.2**。`tiles`、`traps`、`mine` 还在，所以旧的 v1.1 读得进来。没有 `wallet` 时当作 0 金币、没有武器。

```json
{
  "version": "1.2",
  "wallet": { "coins": 0, "weapons": [], "equipped": null }
}
```

`weapons` 里只会出现 `dart`、`blade`、`gun`。`equipped` 必须是已经买下的一把，或 `null`。

商店在摆关，不在试玩里再买。价格：

| id | 名字 | 价格 | 试玩 |
| --- | --- | --- | --- |
| dart | 飞镖 | 15 | 一次三发，各 1 点伤害 |
| blade | 砍刀 | 35 | 身前一刀，2 点伤害 |
| gun | 枪 | 60 | 一发，4 点伤害，间隔更长 |

钱不够不能买。已经买过的再点是装备。试玩右上角显示当前武器。没装备时仍是原来的手里剑，1 点伤害。

金币从哪来：打败一只小怪 +1，打倒鳄王 +8，鳄王身边冒出几枚金币。地图上的金币拾取也加进同一个钱包。打完点「回摆关」再买。联机客人的投掷还是 1 点伤害，不跟武器走。

## 默认关和计分

预设 id：`tonight-waves-v1`（`WBStore.buildDefaultSave` / `custom-play.swampPreset` / `xy-go` 的 `tonightWavesDefault` 三处同源）。

没有 `xygo-custom-level` 存档、或存档里既没有障碍 `tiles` 也没有 `mine.map` 时，用这套默认关。已有孩子改过的存档不覆盖。钱包字段仍按 v1.2 读写；额外记 `lastScore`。可视化工坊仍可读写本机 `music` / `likes`。存档 `audio` 字段由 `wb-audio.js` / 工作台喇叭抽屉读写（先听后选 WIP）。

### 四波跑道（12 列，前两格安全）

| 波 | 列 | 内容 |
| --- | --- | --- |
| 安全出生 | 0–1 | 空 |
| 教 | 2–3 | 金币、地刺 |
| 练 | 4–5 | 火、弹簧 |
| 喘气 | 6 | 金币 |
| 变 | 7–8 | 迷雾、岩石 |
| 喘气 / 断坑 | 9 | 金币；地面缺一格 |
| 考 | 10–11 | 地刺、火（加密） |

怪物和小怪不在这 12 格里摆。试玩（`custom-play`）和联网自制关（`xy-go/?custom=1`）把鳄王和两只小怪放在设计列展开之后的跑道尽头；旗在 Boss 手前。

### 试玩积分（和钱包金币分开）

HUD 显示「积分」。规则：

- 捡地图金币 +10
- 打死小怪 +50（钱包仍 +1）
- 打倒鳄王 +200（钱包仍 +8）
- 过关再加 +150，外加每点剩余生命 +100

结算写入存档的 `lastScore`。工作台里原来的「频率次数 / 摆关预计掉血」色卡还在，那是设计辅助，不是试玩积分。

「波」指教、练、变、考四段节奏，不是看图里的水面波纹。

## 先听后选 · 音频（WIP）

右上角 **喇叭** 打开抽屉（不是第五步）。选 BGM、试听并开关 SFX；写入 `xygo-custom-level` v1.2 的 `audio` 字段，不改钱包 / tiles。可视化工坊 `music` / `likes` 仍可并存。

- BGM 四心情：`explore` / `tense` / `win` / `fail`（占位 wav：`audio/bgm/`）。
- SFX：`walk` `jump` `land` `spike` `fire` `spring` `coin` `hurt` `hit`（`audio/sfx/`）。点一下先听并开关。
- 播放：`wb-audio.js`（`cc.audioEngine`，失败则 HTMLAudio）。
- 试玩 `custom-play` 读同一存档开 BGM，并在跳/落/陷阱/币/受伤/击中处播 SFX；失败切 `fail`，过关切 `win`。
