# 今晚工作台 · 设计记录

这份文档跟着今晚 Cocos 工作台走（PR #14 已合入 main）。设计变了就改这里，和代码一起提交。对照页 `shuyang-ai/learn/level-design.html?path=tonight` 保持不动。

产品壳：仓库根 `index.html` 是 **AI办学小屋**（海军蓝 / 金 / 绿），挂四门课。  
**课程 3** 的深度编辑器是 `visual-workbench.html`（本目录），不是把基础台再压一压陷阱条。

引擎是已经入库的 Cocos2d-JS Lite v3.13（`renderMode: 1`）。不用 Cocos Creator，也不用 TMX。画面是场景里的节点和小图，不是整页截图或 PNG 幻灯片。

## 课的路径

主路径只有四步，不另开第五步：

1. **看图** — 上钩，以及自己决定停
2. **频率** — 一个旋钮：地刺每几秒冒一次，跑一次，再回答哪一点在钓你
3. **摆关** — 放东西、调数字、跑一次；商店和后加的陷阱也在这一步，不单独成课
4. **觉察** — 玩完问一句，并去玩这一关

「去做 → 测一次 → 说感觉」是这课的中心。去玩是旁边的一条路，进 `custom-play.html`。

顶栏文案：① 看图一句、② 频率、③ 摆关工坊、④ 玩完。当前步是绿色，其余是海军蓝。小雨在左，爸爸和妈妈在右。

## 画面方向

目标是旧今晚页的版式、颜色和句子，再用更细的 Cocos 插画画出来。深色壳约 `#0f1230`，金色强调 `#ffe07a`，当前步绿 `#3ecf6a`。

## 陷阱

摆关工具：地刺、火、弹簧、迷雾、岩石、金币、擦掉。

| 格子 | 课上的意思 | 试玩里 |
| --- | --- | --- |
| 地刺 | 每 1 / 3 / 5 秒冒一次 | 冒起时扎人 |
| 火 | 停 1 / 3 / 5 秒 | 一直在，按伤害掉血 |
| 弹簧 | 踩上去会弹起来 | 落地时向上弹 |
| 迷雾 | 走进去会变慢 | 短时间减速，并蒙一层紫 |
| 岩石 | 撞上去会轻伤 | 挡住身体，撞一下掉 1 血 |
| 金币 | 奖励，用来喘气 | 捡到加金币 |

前两格是出生点。地刺、火、弹簧、迷雾、岩石不能放在那里。
