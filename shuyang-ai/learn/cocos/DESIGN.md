## 课的路径

**目标态（权威见 [PRODUCT.md](./PRODUCT.md) §4）**：课件内部教程 **六步** ①看图 ②频率 ③摆关 ④装备 ⑤觉察 ⑥听选。  
**当前实现（WIP）**：顶栏仍是旧四步 ①看图一句 ②频率 ③设计一小关 ④玩完；映射到目标态为 ①②③⑤。④装备（原摆关内武器店）与 ⑥听选（原喇叭抽屉）待升格为显式步骤。

现行四步行为（未改完前仍有效）：

1. **看图** — 上钩，以及自己决定停
2. **频率** — 一个旋钮：地刺每几秒冒一次，跑一次，再回答哪一点在钓你
3. **摆关** — 放东西、调数字、跑一次；商店和后加的陷阱也在这一步（目标态拆到④）
4. **觉察** — 玩完问一句，并去玩这一关

「去做 → 测一次 → 说感觉」是这课的中心。去玩是旁边的一条路，进 `custom-play.html`。主验含 **手机横屏**。小宇在左，爸爸和妈妈在右。

## 画面方向

目标是旧今晚页的版式、颜色和句子，再用更细的 Cocos 插画画出来。

旧页是深色壳（约 `#0f1230`），中间一块圆角画布（频率和摆关的底是 `#6ec8ff`），标题和旋钮在画布外面，脚上是上一步 / 下一步。插画本身沿用旧画布和 `ld-art.js`：水面和钩、蓝天远山、泥土地加草、格子上的道具。要加的是光、材质和层次，不是另一套粗色块。

已经做上的（wb6）：

- 小图在 `wb-art.js`：鱼、金属钩、水面高光、天空渐变、远山近山、带石子的泥土、草叶、刺、火、金币、弹簧、迷雾、岩石。
- 看图、频率、**摆关**都收进深色壳里的圆角画布；标题在画布外。
- 频率有 **真拖滑条**（1–5 秒）＋加减按钮。
- **手机 / 电脑双壳**：`workbench.html` 与 `visual-workbench.html` 同一套关卡数据，顶栏可切「电脑壳 / 手机壳」（`wb-shell` / `vw-shell`）；手机壳强制手机版 Cocos 布局。
- 摆关陷阱条：**短筹码 + 可横滑**（刺/火/弹/雾/石/币/擦），高度压矮；武器店仍在同一页（飞镖15 / 砍刀35 / 枪60）。

- 无存档时用 `tonight-waves-v1` 四波默认跑道（与 custom-play / xy-go 同源）。

已经做上的（wb7）：

- **手机壳 16:9 槽**：`.phone-bezel .canvas-slot` 用 `aspect-ratio:16/9` 居中，避免竖屏槽 + SHOW_ALL 上下大块空金边；电脑壳同比锁定命中区。

## 联网 / 联机在哪

**真实现**：PeerJS（`peerjs@1.5.4` CDN）+ 本机 `BroadcastChannel` 兜底。

| 入口 | 路径 | 说明 |
| --- | --- | --- |
| 课程试玩联机（主） | `shuyang-ai/learn/cocos/custom-play.html`（`?net=1` **单人先开打**） | 玩今晚存档关；`?net=1` 只软邀请（顶栏/横幅匹配，**不**弹「等另一位」挡关）；点「联机游玩」才开房间卡；实现在 `custom-play.js` |
| 工坊露出 | `visual-workbench` 顶栏「联机」+ 右轨 🤝；`workbench` 顶栏「联机」；④步「联机游玩」 | 只跳进上面的真路径，不假匹配 |
| 完整公园联网 | `xy-go/`（`?custom=1` 自制关） | 首页「联机游玩」；同 PeerJS 家族 |
| 旧副本 | `xy-net/` · `xiaoyu-play/` · `xiao-yu/` | 同源旧包，**不作为课程3主入口** |

没有自建房间服务器：靠 PeerJS 公共信令。微信内置浏览器常拦 WebRTC——页面已提示用系统浏览器。不要做「假在线」动画。
**单人优先（2026-11）**：联机是可选项。`custom-play.html?net=1` 与工坊「联机」入口默认立刻可玩；PeerJS 在后台匹配。房间等待 UI 不得挡住移动；取消房间卡 = 关掉卡片，不是必须终止单人局。`xy-go/?net=1` 同样：先 `start` 单机，再 soft match。


## 陷阱

摆关工具：地刺、火、弹簧、迷雾、岩石、金币、擦掉。

| 格子 | 课上的意思 | 试玩里 |
| --- | --- | --- |
| 地刺 | 每 1 / 3 / 5 秒冒一次 | 冒起时扎人 |
| 火 | 停 1 / 3 / 5 秒 | 一直在，按伤害掉血 |
| 弹簧 | 踩上去会弹起来 | 落地时向上弹 |
| 迷雾 | 走进去会变慢 | 短时间减速，并蒙一层紫 |
| 岩石 | 撞上去会轻伤 | 挡住身体，撞一下掉 1 血 |
| 金币 | 奖励，用来喘气 | 捡到加金币 |

前两格是出生点。地刺、火、弹簧、迷雾、岩石不能放在那里。预计掉血：岩石算 1，弹簧和迷雾算 0，地刺和火沿用原来的估算。检查条仍是：开头空着、先易后难、有喘气、花样不超过 3。

## 金币、武器、存档

键名 `localStorage` 的 `xygo-custom-level`。版本 **1.2**。可附带 `music`、`likes`（本机）；试玩积分写 `lastScore`。

键名仍是 `localStorage` 的 `xygo-custom-level`。版本 **1.2**。`tiles`、`traps`、`mine` 还在，所以旧的 v1.1 读得进来。没有 `wallet` 时当作 0 金币、没有武器。

```json
{
  "version": "1.2",
  "wallet": { "coins": 0, "weapons": [], "equipped": null }
}
```

`weapons` 里只会出现 `dart`、`blade`、`gun`。`equipped` 必须是已经买下的一把，或 `null`。

商店在摆关，不在试玩里再买。价格：

| id | 名字 | 价格 | 试玩 |
| --- | --- | --- | --- |
| dart | 飞镖 | 15 | 一次三发，各 1 点伤害 |
| blade | 砍刀 | 35 | 身前一刀，2 点伤害 |
| gun | 枪 | 60 | 一发，4 点伤害，间隔更长 |

钱不够不能买。已经买过的再点是装备。试玩右上角显示当前武器。没装备时仍是原来的手里剑，1 点伤害。

金币从哪来：打败一只小怪 +1，打倒鳄王 +8，鳄王身边冒出几枚金币。地图上的金币拾取也加进同一个钱包。打完点「回摆关」再买。联机客人的投掷还是 1 点伤害，不跟武器走。

### 试玩积分（和钱包金币分开）

HUD 显示「积分」。规则：

- 捡地图金币 +10
- 打死小怪 +50（钱包仍 +1）
- 打倒鳄王 +200（钱包仍 +8）
- 过关再加 +150，外加每点剩余生命 +100

结算写入存档的 `lastScore`。工作台里原来的「频率次数 / 摆关预计掉血」色卡还在，那是设计辅助，不是试玩积分。

「波」指教、练、变、考四段节奏，不是看图里的水面波纹。
